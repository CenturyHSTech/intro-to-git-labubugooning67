## Keywords & things

- Git

Git is a distributed VCS, or Version Control System. That means it's a useful tool for easily tracking changing changes to your code, collaborating, or sharing. It allows you to keep a record of what you've worked on so you can always revert to a previous version if need be.

- GitHub

Allows you to use the power of Git with an easy online interface. It's used all across the software world.

- Repository

Your project folder where the work happens. Contains all of your project files & revision history. 

- Cloning

When a repository is created with GitHub, it's stored remotely in the cloud. You can clone a repository to create a copy on your computer & then use Git to sync the two.

- Commiting & pushing

How you add changes from your local machine to the remote repository in GitHub. You can make a commit when you've made changes to your work you'd like to save at a checkpoint of sorts. You can also add a commit message to tell your teammates what exactly you added. Pushing adds multiple commits to one repository.. I think.

- Branches

Branches store work you do not want to be merged into the main project yet, whether that be because it's untested, experimental, or the like.
